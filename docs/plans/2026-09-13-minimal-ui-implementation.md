## 范围与状态语义

- 新增 `src/lib/taskPresentation.ts`，让渲染上限、普通全选、矩阵代表任务和整批成员共用一份呈现结果。普通全选只选实际显示的代表；“选中整批”可明确包含同格重试历史，并在批量操作说明中显示数量。
- 搜索和状态在导航切换时保留；全部作品取消收藏与分类限制；重复相同导航不额外清除选择。新增回归测试覆盖这些组合。
- 只有 `status === 'error' && error === '已取消生成'` 的记录显示中性色“已取消”。没有通过模糊包含“取消”来吞掉其他失败，也没有修改底层 TaskStatus 或运行调度。
- 保存原有请求、取消、重试、模型兼容处理、IndexedDB、跨标签页租约和持久化合同。持久化结构及 API 实现没有改动。

## 浏览器验收

预览地址 `http://127.0.0.1:5177/`，使用当前工作区的 Vite 开发服务。测试数据通过应用正常合并导入流程进入这个新预览 origin；未读取其他端口的用户作品或 API 密钥。

合成样例包含两个演示对话、11 条终态记录、10 张自绘 PNG、方/横/竖画幅、三输出任务、收藏、失败、取消，以及 2×2 矩阵和一条同格失败历史。另生成 16 张不同 SHA 的 PNG 检查参考图上限。样例都带有演示标记，没有运行中任务，没有外部图像服务请求。

已实际检查：

- 1280px、1440px 桌面浅色布局，390px 手机浅色/深色布局，320px 窄屏与长提示词，768px 导航断点，以及 1024×400 低高度窗口。
- 4:3 画布完整显示方形、横图、竖图；普通页面没有横向溢出；手机长列表下输入仍位于视口内容列底部，矩阵在自身容器中横向滚动。
- 设置桌面分类、手机分类选择、主题草稿与保存、数据合并导入。
- 我的收藏、全部作品、搜索矩阵、整批选中 5 条成员时明确显示其中 1 条历史记录。
- 多输出详情从第 1 张切到第 2 张；1024×400 时图片缩放完整，信息区滚动，操作按钮可见。
- 手机更多与网格浮层未撑宽页面；Esc 返回更多触发器；高级参数切到 JPEG 后压缩率变为可编辑。
- 16 张参考图上传达到上限；长提示词与 16 图在低高度窗口中通过输入面板自身滚动访问提交入口。
- 从参考图打开遮罩编辑器，实际绘制一笔并保存，输入区显示“遮罩已启用”和另外 15 张参考图。

验收中发现并修复了手机输入区随整个列表下移、低高度详情最小高度裁切、收藏菜单宽度挤压操作按钮、滚动参数面板裁切自定义下拉选项等问题。
