## 本次修复

| 问题 | 可复现的触发条件与影响 | 修复 |
| --- | --- | --- |
| 超时重试释放任务租约 | watchdog 接管重试时调用完整终止函数，任务仍在重试却已无锁，另一页可能误标中断 | 分离单次请求中止与任务终止；重试和退避期间保留租约 |
| 入队先于实际获锁 | Web Locks 请求回调尚未执行，running 记录已经写库 | acquire 返回获锁完成信号；入队等待信号后才公开并持久化任务 |
| 启动使用过期 running 快照 | 读任务后、查租约前另一页完成或删除任务，启动页仍把旧记录写为中断，覆盖输出或复活删除 | 对无锁的 running 候选重新读取当前数据库记录 |
| 租约观察者早于初始化写入 | 初始化期间锁已释放，观察回调先执行时任务尚未进 store，或结果被后续快照覆盖 | 任务进入 store 后再注册观察者；同步已完成/删除状态，并等待补标持久化后释放观察锁 |
| pending 清零后接纳迟到快照 | 刷新过程中本地写入或删除已完成，pending 已清空，旧快照仍回滚 done 或复活删除 | 登记和清理均更新本地变更版本；读取期间版本变化就重新读取 |
| 懒加载 chunk 循环重导出警告 | 命令面板通过 taskRuntime 聚合模块导入取消函数，Rollup 报跨 chunk 执行顺序风险 | 命令模块直接导入取消实现；公开聚合导出保留 |

租约及快照测试新增 10 个用例；其中 8 个故障场景在对应修复前运行失败，修复后全部通过。获锁回调延迟及锁请求失败后重试的另外 2 个用例也通过。
